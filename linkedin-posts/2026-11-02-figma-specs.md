Figma just launched the most important feature for design-engineering collaboration since auto-layout.

It's called Specs.

Here's why it matters:

The old way:
→ PM writes PRD in Google Docs
→ Links to Figma mockups
→ Engineer hunts for context
→ Everyone talks past each other

The Specs way:
→ Documentation lives ON the canvas
→ Design frames are embedded (live, not screenshots)
→ Engineers see requirements + designs together
→ AI agents can read and write to Specs via MCP

This solves the #1 friction point in product teams: context scattered across 5 different tools.

**What you can do with Specs:**
• PRDs with embedded designs
• Design system documentation
• Technical handoff specs
• Design crit summaries (AI-generated from FigJam)

Available now in open beta for all paid plans.

Full guide with templates and workflows 👇
